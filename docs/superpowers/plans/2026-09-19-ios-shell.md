# DataRover iOS Shell Implementation Plan

> Execute locally, task by task, preserving existing Xcode project edits.

**Goal:** Implement the approved Figma landscape shell, real Option controls,
logo menu, automatic save/resume and real-time pacing.

**Architecture:** SwiftUI owns presentation and scene lifecycle. The core owns
all MAME operations, snapshots and queued controls on its worker thread.
A complete MAME snapshot resumes the session; battery-backed RAM remains the
fallback across incompatible core versions. Checkpoints use atomic replacement.

**Approved design:** Figma YjOtM5EZSTHBpsyGzUf2Ri, node 572:788. Landscape device
shell with live 480x320 screen, two Option controls and original exported logo.
Both Option controls map to the existing single hardware input; held controls
are combined. The logo opens a native sheet for save, restart and package import.
Package import must distinguish storing a file from successful installation.
Absolute host-clock synchronization is investigation only in this iteration.
